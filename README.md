# tiny-llm-eval
Evaluation framework of small/quantized LLMs that support tool callings on a wide range of benchmarks using Pydantic AI that fit on 2 x NVIDIA RTX 3090 GPUs. 

# Setup

```bash
# Setup UV if you don't have it
curl -LsSf https://astral.sh/uv/install.sh | sh

# Install Python 3.12
uv python install 3.12

```
